## 🛠️ Mac 用户避坑指南

在 macOS 系统安装加速客户端时，若提示“无法打开，来自身份不明的开发者”，请按以下步骤操作：

1. 打开 **系统设置 (System Settings)**。
2. 进入 **隐私与安全性 (Privacy & Security)**。
3. 下拉至 **安全性 (Security)** 栏目。
4. 点击 **“仍要打开 (Open Anyway)”** 即可完成安装。
